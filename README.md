# Ghost Layer (codename doro)

A short stealth game in Godot 4.7. Aigis, the enemy AI, learns the player's habits between Missions and adapts its security. The player's main tool is radio deception: spoofing guards with their own recorded voices.

## Run

Open the folder in Godot 4.7 and press Play (main menu: `ui/main_menu/main_menu.tscn`). LimboAI is vendored in `addons/`; the export target is Windows Desktop.

```sh
godot --headless --path . --import                         # after adding a class_name
godot --headless --path . tools/run_tests.tscn             # the test suite
godot --headless --path . --script tools/build_harbour.gd  # regenerate an Area scene from its data
```

Area scenes under `areas/` are generated by `tools/build_<area>.gd`; edit the data there, never the scene.

## Contributing

Enable the hooks once per clone: `git config core.hooksPath .githooks`. They enforce Conventional Commits and `<type>/<kebab-name>` branches, run the suite on the staged files, and reject scripts over 600 lines.
