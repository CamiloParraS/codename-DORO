## Areas

Generated by `tools/build_<area>.gd` from data; never hand-edit the `.tscn`. Each Area's script (`areas/<area>/<area>.gd`) wires guards, Encounters and objectives. Shared pieces: `areas/extraction_point.gd`, `intel_pickup.gd`, `objective_watch.gd`, `no_fulton.gd`, `target_zone.gd`, `scatter.gd`. Suites: `test_harbour.gd`, `test_harbour_encounters.gd`, `test_core.gd`. The headless playthrough is `tools/play_harbour.tscn` (also `play_core`, `play_relay`, `play_annex`).

## Checks and tools

- `git config core.hooksPath .githooks` enables the hooks. `pre-commit` requires a `.uid` per new `.gd`, then runs `godot --headless --path . --import` and `tools/run_tests.tscn`, blocking on a parse error or a failing test (about 30 s; `SKIP_CHECKS=1 git commit` bypasses it). `commit-msg` enforces Conventional Commits and branch names.
- `tools/scan_shot.tscn` saves a PNG of the Scanner on (windowed, `-- <area>`): see how a change to cones, HUD or world looks without asking the player for a screenshot. `tools/shots.gd` takes fixed Area screenshots.
