# 09: Tranq pistol

**Spec:** [Ghost Layer spec](../../ghost-layer/spec.md)

**What to build:** The Operative can aim over the shoulder and tranquilize guards: headshots drop them instantly, body shots after a stumble.

**Blocked by:** 08, 07

**Status:** ready-for-agent

- [ ] Hold RMB to aim, LMB fires only while aiming; hitscan; key 1 selects the pistol
- [ ] Headshot Neutralizes at once; a body shot Neutralizes after ~3 s, during which the guard stumbles, is suspicious and can't radio
- [ ] 4-dart magazines, 8 total; R reloads early, automatic on empty, ~1.5 s, silent; no reload while carrying
- [ ] Usable one-handed while carrying, with worse accuracy
- [ ] HUD weapon card: pip column for the magazine, name and reserve
