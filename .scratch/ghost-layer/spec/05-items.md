# User Stories: Items

37. As a player, I want a Scanner with 3 charges per Mission that shows guard and camera cones within 30 m through walls for about 10 s, so that I can plan a route when I need to.
38. As a player, I want to throw a Magazine (hold to aim the arc, release to throw about 15 m) that lands as a knock, so that I can draw guards somewhere I am not.
39. As a player, I want to cycle items with the mouse wheel and use them with F, with the count on the HUD item card, so that items are quick to reach.
