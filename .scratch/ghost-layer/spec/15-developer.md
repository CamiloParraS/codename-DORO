# User Stories: Developer

118. As the developer, I want Aigis's planning, Glaukopis's judge and the guard alert state machine as pure, node-free modules, so that I can test them without running a scene.
119. As the developer, I want every binding to go through named InputMap actions, so that controls live in one place.
120. As the developer, I want every line keyed in one CSV translation table, so that writing and translating are tracked in one file.
121. As the developer, I want every third-party asset listed in the credits file, so that the licences are respected.
122. As the developer, I want an ordered cut list and a never-cut floor, so that a slipping week has an answer that has already been decided.
