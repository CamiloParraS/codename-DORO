# Solution: Solution

**Ghost Layer** is a third-person stealth game in a modern-retro PSone look. The player is an Operative of Metis, a mercenary team hired by a whistleblower to find out what Aigis is: Palladion's tactical intelligence, which defends a coastal compound.

Over three Missions and a final Mission at the Core, Aigis profiles the Operative's Habits and, between Missions, deploys Countermeasures that the player can see and hear: cameras, helmets, vests, patrol pairs, sentries, HQ polls, radio callbacks. Its five Voices plan these openly in a Briefing the player overhears, naming the Operative's habits. The post-Mission screen shows Aigis's Profile as a strip of icons. The player can also deceive the guards with Spoofed transmissions made from captured Voiceprints, which Glaukopis judges for authenticity. A silent Lethality tally decides the Dominant Voice, which colours every Briefing and decides which of three endings plays.

The AI design has three layers. Guards run a behaviour tree. Aigis is a deterministic utility AI that acts only between Missions. Profiling feeds Aigis. A Free mode with Presets and an F3 debug overlay lets the presenter show any Profile, any deployment and any ending live, and a short Spanish write-up documents the AI using deployment tables generated by the test suite.
