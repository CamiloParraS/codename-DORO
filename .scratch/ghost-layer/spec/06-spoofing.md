# User Stories: Spoofing

40. As a player, I want guards to radio routine check-ins every 20–30 s, shown as ((·)) over their head and in the subtitles, so that I know when a Voiceprint can be captured.
41. As a player, I want to record a guard's Voiceprint by staying within 6 m for 2.5 s of a check-in, with partial progress kept, so that getting close is the tension.
42. As a player, I want to see the Voiceprints I hold on the HUD, so that I know which guards I can impersonate.
43. As a player, I want a radial radio menu (Q) with time slowed, so that I can compose a Spoofed transmission under pressure without the game pausing.
44. As a player, I want to choose speaker, recipient (one guard or All units), order (go check a place, hold position, all clear/stand down, report in) and place, so that I can steer patrols.
45. As a player, I want guards to obey a convincing Spoofed transmission, so that deception is a real way through.
46. As a player, I want Glaukopis to judge each Spoofed transmission with consistent, readable rules, so that exposure feels fair and learnable.
47. As a player, I want to find out a transmission was exposed through the recipient saying "<X>? You don't sound right. Who is this?", so that I learn it in the fiction, not from a banner.
48. As a player, I want an exposed Voiceprint to be flagged for good and the recipients to search near where I transmitted from, so that a failed spoof has a consequence.
49. As a player, I want to answer an HQ poll with "Report in" in the polled guard's voice, so that Spoofing also lets me cover my tracks.
