# User Stories: Presenter and evaluator

107. As a presenter, I want Free mode to load any Mission with a Preset (Clean slate, Ghost, Trickster, Butcher, Custom), so that I can show any adaptation in seconds.
108. As a presenter, I want Free mode never to touch the campaign's Profile, Lethality or saves, so that the demo is safe to run anywhere.
109. As a presenter, I want the Habit-level cap to still apply by Mission in Free mode, so that what I show matches what a real campaign would give.
110. As a presenter, I want Custom sliders per Habit and for the Lethality ratio, so that I can answer "what if" questions live.
111. As a presenter, I want an F3 debug overlay on every screen, campaign included, showing Profile points and levels, this Mission's tally, Voice weights, the Dominant Voice, Lethality (raw, ratio, band, projected ending), the deployment plan with every candidate's score, Glaukopis's doubt and reasons, and why a guard spotted me, so that I can explain each decision on screen.
112. As a presenter, I want the Briefing to show the plan table while the overlay is on, so that I can connect what the Voices say to how they scored.
113. As an evaluator, I want the same Preset to always give the same deployment, so that the demo and the write-up agree.
114. As an evaluator, I want to see the Harbour empty under Clean slate and then fortified under Butcher at the Core, so that the adaptation is unmistakable.
115. As an evaluator, I want a Spanish write-up (about 4–6 pages) explaining the guard behaviour tree, the Profile, Aigis's utility planning, Glaukopis and the Lethality → ending chain, so that I can assess the game AI.
116. As an evaluator, I want deployment tables for every Preset × Mission generated by the tests, so that the evidence matches the shipped tuning.
117. As an evaluator, I want a one-page demo script I can rerun in Free mode, so that I can reproduce what I was shown.
