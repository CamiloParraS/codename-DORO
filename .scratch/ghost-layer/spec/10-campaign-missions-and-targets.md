# User Stories: Campaign, Missions and Targets

79. As a player, I want three Areas (Harbour, Radio relay station, Research annex), each about 80×80 m with 2–3 approaches, so that every Mission has room for different plans.
80. As a player, I want Mission 1 in the Harbour to teach each verb with a contextual prompt and a Metis radio line the first time I use it, so that I learn without a separate tutorial.
81. As a player, I want a pre-placed eavesdrop spot in Mission 1, so that I learn Spoofing before Aigis can counter it.
82. As a player, I want Mission 2 to have me sabotage the relay (hold to interact for 5 s) and deal with the relay chief, so that objectives vary.
83. As a player, I want HQ to send every guard searching about 30 s after the sabotage, so that the Mission ends under pressure without a forced alert.
84. As a player, I want Mission 3 to have me extract intel and deal with the lead researcher, so that the story moves toward the Core.
85. As a player, I want each Target to be killable on the spot or Neutralized and carried to the Extraction point, so that the biggest Lethality choice in each Mission is mine.
86. As a player, I want Targets to look distinct, walk a fixed route with an escort, and run to a safe room on alert, so that I can find and plan around them.
87. As a player, I want the Core Mission to start where Mission 1 did, in the fully fortified Harbour, so that I see how much Aigis has changed the place.
88. As a player, I want to take the freight lift down to the Core room and deal with the security director beside Aigis, so that the last Lethality decision happens just before the ending.
89. As a player, I want one Checkpoint per objective step, so that dying never costs a whole Mission.
90. As a player, I want a Mission to end at its Extraction point once its objectives are done, so that the finish is clear.
91. As a player, I want the current objective on the pause screen, so that I can always check what to do.
