# Implementation Decisions: Debug overlay (F3)

Available on every screen, campaign included. It shows the Profile (raw points, levels, this Mission's tally, unlocked and deployed steps), the five Voice weights and the Dominant Voice, Lethality (raw, ratio, band, projected ending), the deployment plan (budget, pinned Habit, each pick with its candidates and scores), Glaukopis's doubt and reasons, and the guard alert reason strings. On the Briefing it shows the plan table.
