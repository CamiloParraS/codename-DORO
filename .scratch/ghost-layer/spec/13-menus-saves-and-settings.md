# User Stories: Menus, saves and settings

100. As a player, I want three autosave campaign slots written only when a Mission is completed, so that my progress is safe and simple.
101. As a player, I want Continue, New game, Load, Free mode, Settings and Quit on the main menu, so that I can always find my way.
102. As a player, I want the slot picker to show each slot's next Mission (or "Complete") and when it was last saved, and to confirm before overwriting, so that I don't lose a campaign by accident.
103. As a player, I want Resume, Restart from Checkpoint, Abort Mission, Settings and Quit to menu in the pause menu, so that I control my session.
104. As a player, I want quitting mid-Mission to restart that Mission from its Briefing, so that the rules on saving stay simple and fair.
105. As a player, I want loading a finished slot to replay its finale, so that I can see my ending again.
106. As a player, I want to set mouse sensitivity, invert Y, language, window mode and master volume, and keep them across new games, so that the game is comfortable.
