# User Stories: Story and dialogue

92. As a player, I want a paused, full-screen Codec call with the handler and the analyst before each Mission, so that I know the objective and the Target.
93. As a player, I want short live calls as subtitles over a CALL bar during play (tutorial, intel pickups, relay offline, the lift opening), so that the story moves without stopping me.
94. As a player, I want radio traffic as subtitles at the bottom with the speaker's name, and guard-to-guard chatter only when I'm within hearing range, so that overhearing is a stealth reward.
95. As a player, I want intel pickups to reveal the story beats (the whistleblower, Synthetic Content Inflation, the dead commanders' memories, the Core under the Harbour), so that exploring is worth it.
96. As a player, I want text with PSone-style radio beeps instead of voice acting, so that the game keeps its retro feel.
97. As a Spanish-speaking player, I want every line and UI string in Spanish, switchable live, so that I can play in my language.
